# Above Architects

Modern architecture company website built with Tailwind CSS.

## 🏗️ About

Above Architects is a Uganda-based architecture firm specializing in residential, commercial, and mixed-use developments. This website showcases our portfolio, team, and services with a modern, responsive design.

## 🚀 Technologies

- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first CSS framework (CDN)
- **JavaScript** - Interactive features
- **AOS Library** - Scroll animations
- **Font Awesome** - Icons
- **Google Fonts** - Playfair Display & Inter

## 📁 Project Structure

```
abovearchitect/
├── index.html      # Homepage with hero, stats, and services
├── project.html    # Portfolio with filterable projects
├── about.html      # Team showcase and company story
├── contact.html    # Contact form and Google Maps
├── blog.html       # Blog posts and newsletter signup
├── IMG/            # Image assets
└── photos/         # Additional images
```

## ✨ Features

- **Responsive Design** - Mobile-first approach with hamburger menu
- **Modern UI** - Professional color palette (Navy #2c3e50 + Terracotta #d4633f)
- **Smooth Animations** - AOS scroll effects throughout
- **Project Filtering** - Interactive portfolio categories
- **Contact Form** - Functional mailto integration
- **WhatsApp Widget** - Floating contact button
- **SEO Optimized** - Proper meta tags and semantic HTML

## 🎨 Design System

**Colors:**

- Primary: `#2c3e50` (Navy)
- Accent: `#d4633f` (Terracotta)
- Secondary: `#8b9d83` (Sage)
- Dark: `#1a3a52`
- Light: `#f8f6f3`

**Typography:**

- Headings: Playfair Display (Serif)
- Body: Inter (Sans-serif)

## 🌐 Deployment

The site is ready for deployment to any static hosting service:

1. Upload all files to your hosting provider
2. Update the WhatsApp number in all HTML files (currently: `256XXXXXXXXX`)
3. Add your actual phone number in `contact.html`
4. Ensure all image paths are correct

## 📝 Customization

All pages use Tailwind CSS via CDN - no build process required. Simply edit the HTML files to customize content and styling.
